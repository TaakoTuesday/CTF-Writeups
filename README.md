# CTF Write-ups & Penetration Testing Labs
Welcome! This repository serves as a centralized archive of my technical write-ups for various Capture The Flag (CTF) challenges and retired lab machines (HTB, TryHackMe, Proving Grounds, etc.).

## The primary goal of this repo is twofold:

1. `Continuous Learning`: Documenting the "Why" behind every exploit to solidify my understanding of attack vectors.

2. `Professional Proof-of-Concept`: Demonstrating my methodology, reporting style, and technical proficiency to clients and collaborators.

# 🛠 Methodology
In every write-up, I follow a standardized penetration testing lifecycle to ensure thoroughness:

1. `Reconnaissance & Enumeration`: Identifying the attack surface via Nmap, directory busting, and service analysis.

2. `Vulnerability Analysis`: Mapping findings to known CVEs or identifying logic flaws and misconfigurations.

3. `Exploitation`: Gaining initial access while documenting the specific payload or exploit used.

4. `Post-Exploitation`: Enumerating the internal environment and performing lateral movement.

5. `Privilege Escalation`: Identifying paths to root or Administrator.

# 📂 Repository Structure
Each directory contains the final report (PDF or Markdown) along with any non-sensitive custom scripts or notes used during the process.

The directory name will always be `MachineName`(`Tag`):
- HackTheBox - HTB
-  TryHackMe - THM
-  HackSmarter - HSM
